# 00 — Project Overview

## Visi
Menyajikan berita Indonesia dari berbagai sudut pandang — satu peristiwa, semua portal — biar pembaca bisa lihat framing dan bias tiap media.

## Misi
- Otomatis meng-cluster artikel dari 28 RSS feed ke dalam peristiwa yang sama
- Memberikan ringkasan netral + perbandingan framing tiap portal
- Deteksi blindspot: angle apa yang dilewatkan suatu portal tapi diangkat portal lain

## Tujuan (Goals)
- [x] MVP live: clustering + ringkasan otomatis
- [x] 28 RSS feed dari 11 portal berita
- [x] Digest email harian
- [x] SEO: OG tags, Twitter Cards, JSON-LD, sitemap
- [x] Auth: magic link login via email
- [x] Dark mode
- [ ] 100 pengguna aktif harian
- [ ] Monetisasi (premium / donasi)

## Target Audiens
Pembaca berita Indonesia yang ingin memahami suatu peristiwa secara utuh tanpa terpaku pada framing satu media.

## Unique Value Proposition
Bukan sekadar agregator — Lensa **membandingkan** cara tiap portal membingkai peristiwa yang sama dan menunjukkan apa yang dilewatkan masing-masing.
