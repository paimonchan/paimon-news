# 06 — Legal & Ethics

## Scraping Legality
- [ ] **Indonesia** — UU ITE, UU Hak Cipta (UU 28/2014)
- [ ] **Internasional** — tergantung sumber dan server location

### Best Practices
- ✅ Prioritaskan sumber yang punya RSS/API resmi
- ✅ Cantumkan link sumber asli di setiap ringkasan
- ✅ Rate limiting agar tidak bebani server sumber
- ✅ robots.txt compliance
- ❌ Jangan scraping konten berbayar / paywall
- ❌ Jangan klaim sebagai konten original

## Copyright & Fair Use
- **Summarization** umumnya masuk *fair use* / *transformative work* kalau:
  - Ringkasannya pendek dan berbeda dari aslinya
  - Mencantumkan atribusi sumber
  - Tidak menggantikan kebutuhan membaca artikel asli
- Tapi tetap ada grey area — perlu konsultasi legal kalau serius

## Content Policy
- [ ] Apakah semua sumber berita diizinkan?
- [ ] Filter konten sensitif (hoax, SARA, dll)
- [ ] User report mechanism
- [ ] DMCA compliance

## Privacy (GDPR / UU PDP)
- [ ] Cookie policy
- [ ] Data collection disclosure
