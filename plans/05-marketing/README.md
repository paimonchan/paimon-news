# 05 — Marketing

## Go-to-Market Strategy
- [ ] **Soft launch** — share ke circle sendiri (Telegram, Discord)
- [ ] **Product Hunt** — kalau versi udah cukup matang
- [ ] **SEO** — artikel ringkasan berita bisa terindex Google
- [ ] **Social media** — share ringkasan ke Twitter/X, LinkedIn

## Target Audience
- **Primary:** Pembaca berita yang sibuk, gamau baca artikel panjang
- **Secondary:** Karyawan kantoran, mahasiswa, penggemar tech
- **Tertiary:** English learner (kalau konten bilingual)

## Channels
| Channel | Strategy |
|---------|----------|
| Telegram Channel | Auto-post ringkasan harian |
| Discord | Community discussion |
| Twitter/X | Share highlight berita |
| Newsletter | Weekly digest via email |
| SEO | Landing page + artikel terindex |

## Branding
- Nama: **Paimon News**
- Tagline: *Berita padat, tanpa basa-basi*
- Tone: Casual, informatif, sedikit humor

## Growth Experiments
- [ ] Referral program
- [ ] "Share to WhatsApp" button
- [ ] Embed widget untuk blog lain
